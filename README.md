## 布局与缩写说明

| 标记 | 中文含义 | 如何区分 |
| --- | --- | --- |
| ANSI | 美式布局 | 常见的横条形回车键 |
| ISO | 欧式布局 | 倒 L 形回车键，左 Shift 较短 |
| JIS | 日式布局 | 带日文转换键，空格较短 |
| 型号默认布局 | 官方型号名称未标布局 | 不是通用包，按自己的完整型号选择 |
| HE | 磁轴 | 不与同名机械轴型号混用 |
| HP / LP | 常规高度 / 矮轴型号 | 属于不同硬件型号 |
| Main / RF / Dongle | 主控 / 键盘无线模块 / USB 接收器 | 三种不同的固件组件 |
| Stable / Beta | 正式版 / 测试版 | 每个型号页中分别标明 |

原版与 V2、不同布局、键盘与接收器分别列出，下载时匹配自己的完整型号。

## 归档说明

仅收录官方原始固件包，由本仓库 GitHub Actions 直接抓取，全部放在 Releases 附件中，不从个人电脑上传固件，不加入自定义固件。

按型号分 Release，收录正式、测试和历史版本。主列表直接按版本下载；原始文件名对照和 SHA256 在各页折叠区，与固件一起自动更新。附件按型号、Main／RF／Dongle、版本重命名。

首次全量归档后，每 6 小时触发一次，每天 4 次（北京时间／新加坡时间 02:00、08:00、14:00、20:00）。每次定时运行再独立随机等待 0～30 分钟，随后检查；GitHub 自身也可能延迟调度，因此不是精确时间保证。手动运行不加随机等待。缺资料和目标不符的官方记录会明确标注。Git 文件树仅保留必要抓取流程，不存放固件、源站地址或技术资料。
